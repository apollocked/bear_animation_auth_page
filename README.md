# Bear Animation Auth Pages

A modern authentication app with interactive animations and beautiful Material Design 3 UI.

## Features

### 🎭 Interactive Animations

- **Animated Bear Character**: A charming Rive-based bear mascot that responds to user interactions in real-time
- **Dynamic Eye Movement**: The bear's eyes follow your input as you type in the email field
- **Expressive Reactions**: The bear covers its eyes when you interact with the password field
- **Smooth Transitions**: Fluid animations that enhance the overall user experience
- **State-based Animation**: Different animation states triggered by form focus and user actions

### 🔐 Authentication System

- **Sign In Page**: User-friendly login interface with email and password fields
- **Sign Up Page**: Complete registration interface with password confirmation
- **Mode Switching**: Smooth transitions between sign-in and sign-up modes
- **Form Validation**: Built-in form validation for secure authentication

### 🎨 Modern UI Design

- **Material Design 3**: Fully styled with the latest Material Design 3 system
- **Dynamic Theming**: Adaptive color scheme that works across different lighting conditions
- **Custom Components**:
  - Custom text fields for enhanced user input
  - Custom buttons with elevation and shadow effects
  - Beautiful gradient backgrounds
- **Responsive Layout**: Adapts seamlessly to different screen sizes and orientations

### 🌈 Visual Excellence

- **Multi-layered Gradients**: Beautiful gradient backgrounds with layered color transitions
- **Professional Color Palette**: Carefully selected colors that complement the bear animation
- **Smooth Visual Hierarchy**: Clear emphasis on interactive elements with subtle shadows and effects
- **System UI Integration**: Seamless integration with the system's visual style

### 🔧 State Management

- **Provider Pattern**: Efficient state management using the Provider package
- **Page State Tracking**: Maintains the current authentication page state (Sign In/Sign Up)
- **Reactive Updates**: Real-time UI updates triggered by state changes

### 📱 Technical Highlights

- **Rive Animations**: Professional animation engine for smooth, scalable graphics
- **Material Components**: Complete Material Design 3 component library integration
- **Form Handling**: Robust form management with validation and error handling
- **Clean Architecture**: Well-organized widget structure with separation of concerns
